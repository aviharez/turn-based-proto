# Dialogue style guide (starter)

- Voice: warm adventure with weight. Characters are capable adults; humour is dry, never slapstick.
- Max 2 sentences per line, max 4 lines per conversation (story scenes excepted).
- Concrete over abstract: name the object, the place, the action.
- Indonesian words only where they add flavour and are clear from context (e.g. "candi", "keris"); never italicise them as exotic.
- Every line must do a job: give info, show character, or set a goal.
- Write English first, then Indonesian (id) as a natural translation, not word-for-word.
- Character bibles live in design/lore/characters/<name>.md (voice, wants, fears, 3 sample lines).
